# Dracula userstyles

[Dracula](https://draculatheme.com) palettes for a few web apps, as [Stylus](https://github.com/openstyles/stylus) userstyles.

| Style | Applies to | Install |
|---|---|---|
| `claude-dracula.user.css` | claude.ai dark mode, including Claude Code and the artifact viewer | [install](https://raw.githubusercontent.com/rdjxyz/dracula-userstyles/main/claude-dracula.user.css) |
| `gmail-dracula.user.css` | Gmail, on top of its built-in Dark theme | [install](https://raw.githubusercontent.com/rdjxyz/dracula-userstyles/main/gmail-dracula.user.css) |
| `klaviyo-dracula.user.css` | Klaviyo app (template editor canvas left alone) | [install](https://raw.githubusercontent.com/rdjxyz/dracula-userstyles/main/klaviyo-dracula.user.css) |
| `claude-dracula-glow.user.css` | Claude in Chrome's tab-control glow, orange to purple | [install](https://raw.githubusercontent.com/rdjxyz/dracula-userstyles/main/claude-dracula-glow.user.css) |

With Stylus installed, opening an install link shows Stylus's install page. Stylus keeps the raw URL as the update source and picks up new versions whenever `@version` in the file goes up.
